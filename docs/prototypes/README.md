# Prototypes

Draft files that show what the formats will look like before the core exists. They are not loaded by anything yet, and paths, ports and image names in them are not checked against each tool's docs.

| File | Shows |
| --- | --- |
| [stack.example.yaml](stack.example.yaml) | A stack file for the author's target setup ([spec](../specs/stack-file.md)) |
| [.env.example](.env.example) | The secrets that stack file references |
| [recipes/hermes/recipe.yaml](recipes/hermes/recipe.yaml) | A recipe for Hermes ([spec](../specs/recipe.md)) |
